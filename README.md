# Pokédex de Kanto

Uma Pokédex interativa da primeira geração de Pokémon, desenvolvida com HTML, CSS e JavaScript, utilizando a PokéAPI para obter os dados dos Pokémon.

## Sobre o projeto

O projeto foi desenvolvido com o objetivo de praticar desenvolvimento web front-end, consumo de API REST, manipulação do DOM e organização de código JavaScript.

A interface é inspirada na Pokédex clássica do anime Pokémon e permite explorar os 151 Pokémon da região de Kanto.

## Funcionalidades

- Consulta dos 151 Pokémon da primeira geração.
- Busca por nome ou número.
- Navegação entre Pokémon anteriores e próximos.
- Exibição das imagens obtidas pela PokéAPI.
- Informações de altura e peso.
- Descrição do Pokémon.
- Exibição dos tipos de cada Pokémon.
- Consulta de vantagens e fraquezas de tipos.
- Filtro da lista por tipo.
- Destaque do Pokémon selecionado na lista.
- Interface adaptável a diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** lógica, interatividade e manipulação do DOM.
- **PokéAPI:** fonte dos dados dos Pokémon.

## API utilizada

Os dados são obtidos pela [PokéAPI](https://pokeapi.co/), uma API pública que disponibiliza informações sobre Pokémon.

A aplicação consulta os dados necessários para apresentar os Pokémon, incluindo imagens, tipos, características e descrições.

## Como executar o projeto

1. Clone este repositório ou baixe os arquivos.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` no navegador. Você também pode utilizar a extensão Live Server do VS Code.
4. Mantenha uma conexão com a internet para carregar os dados da PokéAPI.
